# 三甲医院名录

按省份查看三级甲等医院，并对照复旦大学医院管理研究所 2023 年度榜单筛选。

综合榜采用《2023年度中国医院综合排行榜》（2024年11月16日发布）：100 家医院分为 A++++、A+++、A++、A+、A 五档，每档 20 家，同档不分先后。专科榜采用同期《2023年度中国医院专科声誉排行榜》：45 个专科，各取前十名。

名录只收三级甲等医院。未进入综合榜的医院可以浏览，但不会被编造名次。2025 年末全国三甲医院为 1975 家，本站是公开资料整理稿，不是国家卫生健康委的实时全量名录。页首写明了出处和收录数量。

## 本地运行

```bash
npm install
npm run dev
```

开发服务地址是 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

生成静态文件：

```bash
npm run build
```

产物在 `out/`。

## 扩充名录

医院在 [`data/hospitals.json`](data/hospitals.json)，专科前十在 [`data/specialties.json`](data/specialties.json)，榜单年份和全国三甲总数在 [`data/meta.json`](data/meta.json)。

新增一家三甲医院时，在 `hospitals.json` 增加一条记录：

- `id`：站内唯一，例如 `h173`
- `name`、`province`、`city`
- `region`：华北、东北、华东、华中、华南、西南、西北
- `type`：综合、专科、中医、妇幼儿童
- `tier`：五档之一；未上综合榜则写 `null`
- `tierOrder`：综合榜发布顺序；未上榜写 `null`

`province` 使用简称，例如 `北京`、`内蒙古`，不要写“省”或“市”。只放入能够核对等级的三级甲等医院。不要为了凑数填写综合名次。

[`scripts/build-data.mjs`](scripts/build-data.mjs) 用来从榜单整理稿重新生成上述 JSON。手改 JSON 之后不必再运行它，否则手改会被覆盖。
